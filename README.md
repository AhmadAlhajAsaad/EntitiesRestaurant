# EntitiesRestaurant

A simple .NET 8 console project defining restaurant-related entity models for an order-delivery system.

## Contents

- `Program.cs` — entity classes for restaurants, menus, orders, users, and couriers.
- `EntitiesRestaurant.csproj` — .NET 8 project file.

## Requirements

- .NET 8 SDK

## Run

```bash
dotnet run
```

## Notes
- This project currently uses a single source file, `Program.cs`, with all entity definitions.
- Nullable reference types are enabled.
